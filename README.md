## 作品概要
- **開発環境**：C++ / Unreal Engine 5
- **開発期間・人数**：2026年3月～2026年9月（6ヶ月）（継続開発中） / チーム制作（担当：敵関連システム全般）

## 特徴
- 地雷系女子が、浮気した彼氏と浮気相手に復讐する3Dアクションゲーム
- C++とBehaviorTreeを連携させた、拡張性の高い敵AIシステム
- Subsystemによる「攻撃トークン制度」を用いた、破綻のない集団戦アルゴリズム

## 技術的工夫
### 1. AIControllerとBlackboardを一元同期するステート遷移
ChangeEnemyState関数を用意し、C++内部のEnum変更・Blackboardへの値書き込み・移動速度変更などを一箇所で安全に同期する設計にしました。

### 2. 基底クラスと派生による拡張設計
共通のヒット判定や死亡処理などは基底クラス（EnemyCombatComponent）に集約し、各敵キャラクター特有の挙動や処理などは派生クラスに分離することで、カプセル化と拡張性を両立しました。

### 3. SubSystemを用いた「攻撃トークン制度」の導入
複数体の敵が同時に攻撃を行うことによる、回避不能な状態を防止する設計を導入しました。
また、敵の状態遷移時や死亡時にもトークンを自動で返却するフォールバック処理を実装し、トークンリークを防ぎつつ破綻のない集団戦を実現しました。


## 課題と解決策
- **課題：** Motion Warpingを用いて攻撃時にプレイヤーへ追従させる際に、至近距離で攻撃を発動すると敵キャラクターがプレイヤーと重なり、反対方向（180度逆）を向いて攻撃してしまう不具合が発生。
- **原因と解決：** ターゲット座標を「プレイヤーの座標そのもの」に設定していたため、密着時に位置関係が逆転し回転補正が破綻してしまうことが原因でした。<br>
敵からプレイヤーへの方向ベクトルを算出し、プレイヤーの中心ではなく攻撃が届く手前で止まるよう、オフセットを減算した目標座標 (PlayerLoc - (DirToPlayer * StopOffset)) を動的に計算する処理を導入することで、至近距離でも正しくターゲットを向いて攻撃するよう修正しました。

## 操作方法
| キー / ゲームパッド | 動作 |
| :--- | :--- |
| **WASD / 左スティック** | 移動 |
| **マウス移動 / 右スティック** | カメラ移動 |
| **左クリック / 〇ボタン** | 攻撃 |
| **右クリック / △ボタン** | カウンター |
| **Spaceキー / ×ボタン** | 回避 |
| **Zキー / □ボタン** | 覚醒 |
